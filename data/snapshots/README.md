# 隨程式部署的行情存檔

這些行情資料來自 Yahoo Finance，權利屬於原資料來源，不在本專案 AGPL-3.0 授權的範圍內。

這個資料夾裡的 `<代號>.csv` 是最後備援：即時來源連不上、`.yf_cache/` 也沒有存檔時才會用到。用到時畫面會標明存檔日期。

目前包含（2026-11-12 取自 Yahoo Finance）：00878.TW、00631L.TW、0056.TW、0050.TW、006208.TW、00919.TW、00929.TW、00713.TW。

存檔是來源的原始資料，沒有經過分割還原；還原在讀取之後才做，所以規則更新時不必重新產生。

更新或新增：

```bash
python market_data.py 00878.TW 00631L.TW 0056.TW 0050.TW 006208.TW 00919.TW 00929.TW 00713.TW --dir data/snapshots
```

存檔會越放越舊，建議每隔一段時間重跑一次再提交。
