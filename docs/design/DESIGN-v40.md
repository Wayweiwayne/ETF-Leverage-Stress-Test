## 0. 全域規則（四個故事共用）

| 編號 | 規則 |
|---|---|
| G-1 | **一個概念只用一個名字**，畫面、說明頁、報告、CSV 都一樣（SPEC 5「報告與畫面用同一套名稱」）。名字以第 1 節的對照表為準。 |
| G-2 | 圖表的**畫面標題和報告標題用同一個字串**。現在 `show_chart(heading, …)` 的 heading 和畫面上 `st.markdown("##### …")` 是兩個不同的字串，要改成同一個變數。 |
| G-3 | 金額：中文介面延續現在的 `$25,000`；貸款本金這類大金額用「萬」：`820 萬`、`10,000 萬`（不換算成「億」，和輸入欄位的單位一致）。英文介面規則見第 4 節。 |
| G-4 | 百分比：一位小數 `2.6%`。**例外**：和目標破產率差距小於 0.1 個百分點時用兩位小數（例如 `4.95%`、`5.02%`），避免「5.0% 卻說沒達到 5%」這種自相矛盾。 |
| G-5 | 新寫的中文說明用全形括號「（）」；版本號維持半形 `(V40)`（`test_app.py` 檢查 `({APP_VERSION})`）。既有輸入欄位的單位寫法 ` (萬)`、` (%)` 不改，避免無意義的變動。 |
| G-6 | 網址參數**一律不改名**。下拉選單和單選鈕在網址裡存的是**位置**（`ui.choice` 的 universe 索引），所以改選項文字不會影響舊連結；但不可以改選項的**順序**，也不可以從中間插入。 |
| G-7 | 核取方塊的標籤不要用 ✅ 開頭（現在「✅ 啟用配息再投入」在沒勾選時看起來像已勾選）。 |

### 2.4 熱圖：破產機率地圖

**S-30 標題**（畫面 `#####` 小標＝報告圖表標題）：「破產機率地圖：借多少 × 每月自掏多少」

**S-31 資料**：依 SPEC 4.2，本金與自掏上限各取目前值的 0.5、0.75、1、1.25、1.5、2 倍；自掏上限為 0 時改用 0、5,000、10,000、20,000、30,000、50,000。送進 `sensitivity_grid` 前四捨五入到整數元，讓標籤和實際算的值一致。

**S-32 座標軸**
- x 軸標題：「每月最多自掏（元）」；刻度 `$12,500`、`$25,000`…（千分位、整數）
- y 軸標題：「貸款本金」；刻度 `250 萬`、`500 萬`…（衝刺 2 修訂：採用 RD 的格式——以萬為單位、千分位、最多 4 位小數並去掉尾端的 0，例如 `249.75 萬`、`10,000 萬`。原寫的 `.4g` 會把 1 億顯示成 `1e+04 萬`，是設計錯誤）
- （衝刺 2 修訂）兩軸都去掉四捨五入後重複的值（本金很小時 0.5 倍和 0.75 倍可能變成同一個整數元），重複的列／欄只留一個；格數因此可能少於 6×6。
- **兩軸都要設 `type="category"`**。原型實測：刻度字串像 `$12,500` 時 Plotly 會自動當成數字軸，格子寬度變得不一樣、目前格的外框也會畫錯位置。
- 方向：y 軸由下往上本金遞增（類別軸的預設），x 軸由左往右自掏遞增。所以**左上角最危險、右下角最安全**。

**S-33 格內文字**
- 每格顯示破產機率，一位小數 `2.6%`（依 G-4，接近目標時兩位）。
- 目前設定那一格多一行：`2.6%<br>◆ 目前`。
- 字色不要指定：Plotly 6.7 的 heatmap `texttemplate` 會依格子顏色自動選黑字或白字（原型已確認，深淺主題都正確）。

**S-34 配色（離散四段，藍＝在目標內、紅＝超過）**

先在 Python 端把每格分到 0～3 段（**用破產率實際值分段，不靠 Plotly 連續色階**），z 用段號，格內文字用實際破產率：

| 段 | 條件（t＝目標） | 顏色 | 色標文字（t=5% 時） |
|---|---|---|---|
| 0 | r ≤ t/2 | `#1c5cab`（深藍） | 很安全（≤ 2.5%） |
| 1 | t/2 < r ≤ t | `#86b6ef`（淺藍） | 達標（2.5%–5%） |
| 2 | t < r ≤ 2t | `#f0938f`（淺紅） | 超過（5%–10%） |
| 3 | r > 2t | `#b8322f`（深紅） | 危險（> 10%） |

- 等於邊界值算在較安全那段（`≤`），所以剛好等於目標的格子是「達標」。可用 `np.digitize(z, [t/2, t, 2*t], right=True)`。
- 色階：`zmin=-0.5, zmax=3.5`，colorscale 用四個等寬色塊（每段的起點和終點同色）。
- 色標（colorbar）：標題「破產機率」，`tickvals=[0,1,2,3]`，`ticktext` 用上表最右欄（數字依目標代入：1% → 0.5%／1%／2%；10% → 5%／10%／20%）。
- `xgap=2, ygap=2`：格子之間留 2px 縫，縫會露出頁面底色，深淺主題都自然。
- 深淺主題用同一組格子顏色：格子自帶對比足夠的字色（白字在深藍 6.6:1、在深紅 5.9:1；黑字在淺藍 9.3:1、在淺紅 8.7:1），不需要切換。配色用 dataviz 驗證腳本檢查過：四色兩兩在紅綠色弱模擬下 ΔE ≥ 13.8（門檻 8），一般視覺 ≥ 19。

## 5. RD 實作時最容易出錯的地方

1. **熱圖軸沒設 `type="category"`**：`$12,500` 這種刻度會被 Plotly 當數字，格子寬度不一、目前格外框錯位（原型實際踩到）。

3. **目前格位置寫死索引 2**：自掏上限為 0 時目前格在第 0 欄（S-35）。
4. **熱圖用 1,000 次、主結果用 2,000 次**：目前格和上方破產率對不起來（S-38）。
5. **`tgt` 用 `ui.choice(by_value=True)` 配上整數選項**：`by_value` 從網址讀回來的是字串 `"10"`，不在 `[1, 5, 10]` 裡，會被靜靜重設成預設。選項要用字串，或自己 parse。
6. **過期時畫面混用新舊設定**：結果是舊的，但「這次有開啟」、貸款指標、逐月明細、報告設定表、報告的分享連結卻是新的（R-60）。所有結果區的內容都要從快照產生。

### 7.2 本金「整個範圍都達標」與相關說明句（RD 問題 b）

舊句「這通常代表每月自掏的上限設得很高」**作廢**。借越多，每月還款和買進的資產都等比例變大，固定的自掏上限佔比越來越小，所以破產機率會慢慢接近「完全不自掏」時的水準，不會一直往上。實測也看得到：薪水沒排進順位時，36 格全部是 22.9%；`salary=10000` 時，「500 萬／$10,000」和「1,000 萬／$20,000」這兩格的破產機率相同。
